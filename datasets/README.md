# Датасеты

Изображения и разметка в git не хранятся (см. `.gitignore`). Ожидаемая структура:

```
datasets/
├── raw/<сессия>/            # исходные кадры с камеры, сессия = дата_свет_расстановка
├── labeled/<версия>/        # экспорт из CVAT/Label Studio в формате YOLO
├── splits/<версия>/         # train/val/test = 70/15/15, разбиение по сессиям
└── CHANGELOG.md             # версия, дата, число изображений, источник (ТЗ 4.4.4)
```

Классы и индексы (совпадают с `object_types.model_class_index`):

| Индекс | Код | Класс |
|---|---|---|
| 0 | `box` | Коробка |
| 1 | `pallet` | Паллета |
| 2 | `container` | Контейнер |
| 3 | `person` | Человек |

Тестовый набор снимается отдельной сессией последним и не используется при подборе гиперпараметров.
