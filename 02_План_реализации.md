# План реализации

## ИС «Цифровой двойник склада» (к ТЗ ЦДС-2026, ред. 2.0)

---

## 1. Исходные предпосылки

| Параметр | Значение |
|---|---|
| Исполнитель | 1 разработчик (студент 4 курса) |
| Длительность | 16 недель (~4 месяца) + 2 недели резерва |
| Нагрузка | ~20 ч/неделю |
| Оборудование | 1 промышленная камера (Basler acA5472-17um или Hikrobot MV-CE200-10UM) + Computar 12 мм F2.6 |
| Основной стенд | Настольный макет склада, камера на высоте ~1 м (вариант А ТЗ) |
| Дополнительный стенд | Демо-зона 5 × 4 м, камера на высоте 4–6 м (вариант Б), если позволит время |
| Методология | Итеративная: 2-недельные итерации, в конце каждой — работающее демо |

**Выбор камеры для прототипа:** Basler — `pip install pypylon`, поддержка macOS/Linux/Windows, проще интеграция. Hikrobot — если планируется вариант Б (питание 12 В, биннинг 2×2). Код захвата пишется через общий интерфейс, поэтому выбор не блокирующий.

## 2. Технологический стек

| Слой | Выбор | Почему |
|---|---|---|
| Backend | Python 3.11, FastAPI, SQLAlchemy 2, Alembic, Pydantic | Один язык с CV, автодокументация OpenAPI |
| Очередь задач | RQ + Redis (прототип) | Проще Celery, достаточно для 1 камеры |
| БД | PostgreSQL 15 | Надёжность, JSONB, индексы |
| CV | OpenCV, Ultralytics YOLO11n/s, SAHI, zxing-cpp | Готовый конвейер обучения, тайлинг, штрихкоды |
| Камера | `pypylon` / MVS SDK, интерфейс `CameraSource` | Изоляция вендоров |
| Frontend | React + TypeScript + Vite, react-konva, TanStack Query, Recharts, Ant Design/MUI | Быстрая сборка UI, canvas для плана |
| Отчёты | openpyxl, WeasyPrint | XLSX и PDF |
| Инфраструктура | Docker Compose (db, redis, api, worker, web), MinIO — опционально | Развёртывание одной командой |
| Разметка | CVAT или Label Studio (локально в Docker) | Экспорт в YOLO |
| Обучение | Локальный GPU или Google Colab / Kaggle | Нет зависимости от железа |
| Тесты | pytest, httpx, Playwright | Unit, API, e2e |

## 8. Ключевые технические решения

1. **Тайлинг вместо уменьшения кадра.** Коробка 3 см на макете при 0,2 мм/пикс занимает ~150 пикс на 20 Мп кадре, но ~17 пикс после уменьшения до 640 — на грани обнаружения. Тайлы 1280 сохраняют масштаб.
2. **Модель на монохроме.** Три одинаковых канала на входе; цветовые аугментации (hue/saturation) отключены.
3. **Опорная точка.** Вид сверху → центр bbox; наклонный вид → середина нижней грани (точка контакта с полом), иначе гомография пола даёт смещение по высоте объекта.
4. **Сопоставление через QR на части объектов.** Без идентификаторов «перемещение» одинаковых коробок неотличимо от «исчезла + появилась» — это честно отражается флагом `is_assumed`.
5. **`disappeared` после N = 2 сканов.** Защита от единичных пропусков детектора.
6. **Отбраковка кадров с людьми.** Иначе человек, заслонивший стеллаж, порождает ложные исчезновения.
7. **Хранение.** Полный кадр в JPEG q=90 с ограниченным сроком, превью 1600 px и детекции — бессрочно.
8. **Один процесс-воркер на камеру.** Камера USB3 не допускает одновременного доступа из нескольких процессов.
